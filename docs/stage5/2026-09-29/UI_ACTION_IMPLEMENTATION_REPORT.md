## 实测发现与修改

首次从小程序活动详情报名时，订单创建与付款意图创建成功，随后 `/api/mock/payments/:id/succeed` 返回 400：`Body cannot be empty when content-type is set to 'application/json'`。客户端请求封装始终声明 JSON，却在没有字段的动作 POST 中传递 `undefined`。通知已读也使用该路径。

`apps/miniapp/src/api.ts` 现在为未显式提供数据的 POST/PUT 发送空 JSON 对象，GET 与已有请求体沿用原数据。`api.test.ts` 新增模拟 API 空 JSON 报文拒绝规则的回归断言，同时验证模拟付款确认和通知已读。没有改 API 路由、资金状态机或 Schema。
