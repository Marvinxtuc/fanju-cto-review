# 支付上线评审：生产微信支付

## 状态

待审批。本文档只定义生产支付接入前置条件，不代表已经允许接入生产微信支付。

## 结论

在完成本评审前，只允许使用 mock 支付、微信支付测试环境或测试商户号。不得接入真实生产支付，不得提交真实商户号、APIv3 密钥、证书、私钥、token 或生产凭证。

## 必须完成的评审材料

- 商户资料：商户号、主体、业务类目、支付产品权限、退款权限，仅记录获取方式和保管位置，不记录真实值。
- 密钥与证书管理：APIv3 密钥、商户 API 私钥、证书序列号、平台证书必须通过本地未提交 `.env`、密钥管理服务或部署平台 secret 注入。
- 回调验签方案：支付和退款回调必须校验签名、证书序列号、时间戳和幂等键。
- 资金状态机：订单、支付、退款状态必须以服务端和渠道回调为准，不信任前端支付成功状态。
- 对账与异常处理：支付成功但订单关闭、退款超时、重复回调、回调晚到、金额不一致都必须有处理路径。
- 灰度方案：生产支付必须先对白名单或内部账号开放，保留停止新收费的开关；真实交易必须沿原渠道接收回调、查询和退款，禁止回退到 Mock。
- 日志与告警：不得记录完整 openid、手机号、支付敏感字段、APIv3 密钥、证书内容或私钥路径；支付/退款失败必须告警。

## 实施准入条件

以下条件适用于真实渠道联调与生产放行。经用户专项批准的本地资金状态机、Schema、任务及隔离测试整改可以先行；2026-09-29 A2 授权见 `docs/stage2/2026-09-29/LOCAL_FUNDING_DESIGN.md`，不表示真实支付获批。

真实联调前必须满足：

- `FEATURE_REAL_WECHAT_PAY` 默认仍为 `false`。
- `.env.example` 只包含变量名和空占位，不包含真实值。
- 支付 SDK 或自研签名方案已完成安全 review。
- 支付/退款回调幂等测试通过。
- 金额由服务端根据活动服务费/订位费计算，前端金额字段被忽略。
- secret 扫描通过。

## 明确禁止

- 不得提交真实 `.env`、APIv3 密钥、商户私钥、证书、商户号、token 或生产回调样例。
- 不得把生产支付配置硬编码到前端、小程序包、API 源码、测试夹具或 README 示例。
- 不得在未完成回调验签和幂等测试时打开生产支付。
- 不得做不可逆迁移或删除支付/退款数据。

## 参考依据

- 微信支付 API v3 接入需要商户号、APIv3 密钥、商户 API 私钥、证书序列号等敏感材料，并需要处理平台证书、回调验签和报文解密。参考：https://pay.weixin.qq.com/docs/merchant/development/interface-rules/signature-verification.html
- 生产密钥如疑似泄露，必须立即轮换并复核提交历史、部署环境和日志。

本文档不是支付上线许可；正式上线前需要商户平台、财务、法务、安全和运营共同验收。
